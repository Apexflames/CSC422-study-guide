1. Memory System & Hierarchy

Source
Computer memory is any physical component that can be used to temporarily or permanently store data, information or instruction.
Plain English
Anything in the computer that can hold data — for a split second, or forever.
  • Primary memory
  • Secondary memory
  • Cache memory
  • Register memory

Primary Memory — RAM: DRAM vs SRAM

Source
RAM: It is volatile. CPU usually relates with RAM. It is the hardware to temporarily store data, programs or program results. If a power failure occurs or a computer is turned off, the information stored in RAM is lost.
FeatureDRAMSRAM
Refresh neededYes, continuousNo
SpeedSlowerFaster
CapacityHolds moreHolds less
Cost / PowerCheaper, lower powerExpensive, higher power
Example
Main system RAM = DRAM (cheap, lots of it). CPU cache = SRAM (small, fast, pricey per byte).

Primary Memory — ROM

Source
ROM stores data on a chip indefinitely... you cannot write to it or modify it. The crucial program data or instructions needed to boot a computer are contained in ROM.
  • Masked ROM — burned in by the manufacturer, never changeable.
  • PROM — blank chip, user writes once with a PROM burner.
  • EPROM — erasable with UV light after removal from the circuit.
  • EEPROM — erasable electrically, no UV or removal needed. Exam distinction: EPROM needs UV; EEPROM erases electrically.
  • Flash ROM — written/erased in sectors; survives power loss.

Registers & Cache Levels

Source
Registers: tiny fast memory within the CPU, 16–64 bits. Smallest capacity, fastest access. Cache memory: compact fast memory near the CPU, holds frequently used data to reduce retrieval time.
LevelSpeedCapacity
L1Fastest, closest to coreSmallest
L2Slower than L1, faster than L3Larger than L1
L3Slowest of the threeLargest, shared across cores

Quick Revision — Memory System

  • RAM = volatile (DRAM needs refresh, SRAM doesn't). ROM = non-volatile; Masked → PROM → EPROM (UV) → EEPROM (electrical) → Flash (sectors).
  • Registers fastest/smallest; L1 < L2 < L3 in capacity, opposite in speed.
  • Hierarchy: Register → Cache → Main Memory → Hard Disk → External Memory.

Definition of A (DRAM): Capacitor+transistor cell, needs continuous refresh.
Definition of B (SRAM): Static latch, no refresh needed.
Key differences: DRAM slower/cheaper/denser; SRAM faster/pricier.

Likely Question

Q: Explain EPROM vs EEPROM.

Answer: Both retain data without power and are reprogrammable. EPROM must be removed and exposed to UV light to erase. EEPROM erases electrically, in-circuit, no UV needed.

2. Word & Byte Addressable Memory

Source
A memory address is a binary number placed on the address bus by the CPU. In byte addressable memory, each address corresponds to exactly one byte. In word addressable memory, each address corresponds to a whole word; to get one byte, the CPU must fetch the entire word and extract it.
Note (source)The difference between CISC and RISC: RISC is simpler and faster, CISC is complex.
Example 1 — Word addressable: 2¹⁰ addresses, word = 32 bits → 1024 × 4 = 4096 bytes = 4 KB
Example 2 — Byte addressable: 2¹⁰ addresses → 1024 × 1 = 1024 bytes = 1 KB
Example 3 — Bits for 4096 bytes: log₂4096 = 12 address bits
Example 4 — 32 KB, word = 32 bits: 32,768 / 4 = 8192 = 2¹³ → 13 address bits

Quick Revision — Addressing

  • Byte addressable: 1 address = 1 byte. Word addressable: 1 address = 1 word.
  • Total size = addresses × bytes-per-unit. Address bits = log₂(number of units).

Likely Question

Q: 2¹² addresses, word addressable, word = 16 bits. Find total memory size.

Given: 4096 words, 16 bits = 2 bytes/word
Working: 4096 × 2 = 8192 bytes
Final Answer: 8 KB

Source
Cache memory mapping determines how data from main memory is placed in the cache. Three primary techniques: Direct, Full Associative, Set Associative.

Full Associative Mapping

Source
Any block can be placed into any line. Address = Tag + Offset. The tag is compared against all tags in the cache.
128 words, 8 words/line: Offset=log₂8=3, bit addr=log₂128=7, Tag=7−3=4

Set Associative Mapping

Source
Compromise between direct and fully associative; cache divided into sets, each containing multiple lines. Address = Tag + Set Index + Offset.
FeatureDirectFull AssociativeSet Associative
Placement1 fixed lineAny lineAny line in 1 set
Address partsTag,Index,OffsetTag,OffsetTag,Set,Offset
Conflict missesHighLowestReduced vs Direct
Hardware costLowestHighestModerate

Quick Revision — Cache Mapping

  • Direct: cheap, one spot, more collisions. Full associative: flexible, expensive, all-tags search. Set associative: middle ground.

Likely Exam Questions

Likely Question

Q: Compare direct mapping and full associative mapping.

Direct: block → exactly 1 line via mod; cheap, collision-prone.
Full associative: block → any line, all tags searched; flexible, costlier hardware.

4. Virtual Memory

Source
Virtual memory gives illusion of large contiguous memory even if physical RAM is limited; separates virtual address from physical address, uses both RAM and Disk, loading only needed parts.
  • Paging: virtual memory in fixed pages, physical memory in matching frames; unused pages move to disk swap space.
  • Page Tables: track which virtual page maps to which physical frame.
AdvantagesLimitations
Multiprogramming via demand paging; security via isolated address spacesThrashing — excessive swapping; Page fault — OS pauses, fetches page from disk, updates frame table

Likely Exam Questions

Likely Question

Q: What is thrashing?

RAM exhausted → system spends more time swapping pages than executing instructions → slower performance.

5. Control Unit

Source
Control Unit directs the operation of the processor by generating control signals.
FeatureHardwiredMicroprogrammed
Signals fromFixed logic circuitsMicro-instructions in control store
SpeedFasterSlower
Modify instruction setRequires rewiring — hardEasy, flexible
Typical useRISC—
  • Control word — bits representing the signal for one step.
  • Micro routine — sequence of control words for one instruction.

Likely Question

Q: Compare hardwired and microprogrammed control units.

Hardwired = fast, fixed circuits, hard to modify (RISC). Microprogrammed = slower, stored control store, easy to modify.

DMA Modes

  • Burst Mode — DMAC takes full bus control, transfers whole block; CPU stalls.
  • Cycle Stealing Mode — one byte/word at a time, then returns bus to CPU.

7. Fault Tolerance Technique

Source
The design and implementation technique that allows a system to continue working even when one or more devices fails.
  • Triple Modular Redundancy — 3 copies run simultaneously, majority vote wins; detects only one fault at a time.
  • Information Redundancy — e.g. parity bits, detect/correct errors.
  • N-version Programming — independently written versions run simultaneously, best output chosen by majority vote.
  • Exception Handling — detects abnormal events, redirects execution to prevent error propagation.
ApplicationsAviation, medical systems, space exploration, industrial automation.

Likely Exam Questions

Likely Question

Q: Explain Triple Modular Redundancy.

Three redundant module copies run the same task simultaneously; outputs are voted on and the majority result is used. Only detects a single fault at a time.

8. Parallelism & Flynn's Taxonomy

Source
Parallelism is the ability of a computer system to perform multiple operations simultaneously to improve computational speed and system performance.
ConcurrencyParallelism
Rapidly switching between tasksExecuting at the exact same time
  • Bit-Level — bigger word size, more bits at once.
  • Task-Level — decompose into sub-tasks, run simultaneously.
  • Data-Level — same operation on many data elements.
  • Instruction-Level — Pipelining (overlap execution) or Superscalar (multiple ALUs, multiple instructions/cycle).

9. Harvard vs Von Neumann Architecture

Source
Harvard architecture overcomes the Von-Neumann bottleneck by using separate memory for instructions and data, separate buses, allowing simultaneous fetch. Originated in the 1940s.

Likely Exam Questions

Likely Question

Q: Explain how Harvard architecture eliminates the Von Neumann bottleneck.

Von Neumann shares one memory/bus, so instruction and data fetches queue sequentially. Harvard uses separate memories and buses, so instruction and data fetch happen in the same clock cycle — removing the wait, at the cost of more hardware complexity.

10. Systolic Array

Source
A configuration of processors that rhythmically perform computation and transfer data throughout the network, inspired by the rhythmic flow of blood through the heart. A processor performs a small computation and passes the result to neighbouring processors until the final output is obtained.

  • Input/Output channels — feed data in, collect results out.
  • Communication links — between neighbouring elements.
  • Clock — synchronizes the whole array.
TypeLayoutApplications

Two-DimensionalRows/columns (most common)Matrix multiplication, neural nets, image processing
Multi-DimensionalMulti-direction gridDSP, deep learning, Google TPUs

Q: Explain a systolic array and its components.

A grid of processing elements that rhythmically compute and pass data to neighbours until a final result emerges. Components: PEs, input/output channels, communication links, clock. Used in matrix multiplication and Google's TPUs.

Glossary

DRAM — needs continuous refresh, slower, cheaper, denser than SRAM.
SRAM — no refresh needed, faster, pricier than DRAM.
Firmware — software in ROM that controls the processor.
Tag / Index / Offset — the three parts of a cache address: verifies data, locates line, locates byte.
Thrashing — excessive page swapping slowing the system.
Page Fault — accessing a virtual page currently on disk.
DMA — I/O devices transfer data directly to/from memory, bypassing the CPU.
Message Passing — explicit communication method in distributed-memory systems.
Systolic Array — grid of PEs rhythmically computing and passing data to neighbours.
